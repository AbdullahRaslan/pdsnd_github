# Project Title
Bikeshare Data Exploration

## Description
This project analyzes US bikeshare data to answer common questions about travel patterns (user types, trip durations, popular stations, and time-based trends). The repository contains code and notebooks to load, clean, analyze, and visualize the data.

## Files used
- README.md — this file
- bikeshare.py — data processing and analysis
- new_york_city.csv — sample CSV used for testing/analysis 

## How to run
1. Create and activate the conda environment (example):
   conda env create -f environment.yml
   conda activate pdsnd_github
2. Run the analysis scripts or open the notebooks in Jupyter.
